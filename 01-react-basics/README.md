# React Basics

This is a simple React application that demonstrates the basics of React, including components, state, and props. The application consists of a main `App` component that renders a list of items and allows users to add new items to the list.

## Create the app

`npm create vite@latest 01-react-basics -- --template react-ts`

## Packages

### SASS

`npm i -D -E sass@1.77.6`

### Bootstrap

`npm i -D bootstrap`
