# Better Todos

## Re-create

Make a copy of `04-async-todos` and rename the app. Also update package name in `package.json` and the `<h1>` in `App.tsx`.

## Install dependencies

```bash
npm install
```

## Run

Start **both** the React app and the json-server in separate terminals:

### Terminal 1 (React app)

```bash
npm run dev
```

### Terminal 2 (json-server)

```bash
npm run server
```
