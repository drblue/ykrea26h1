# Recommended VS Code extensions

## 🤓 “Essential”

### Auto Import

<https://marketplace.visualstudio.com/items?itemName=steoates.autoimport>

Automatically finds and inserts import statements for your JavaScript and TypeScript code. Saves time when adding new components, functions, or modules.

### Auto Rename Tag

<https://marketplace.visualstudio.com/items?itemName=formulahendry.auto-rename-tag>

Automatically renames paired HTML/JSX tags. Helps maintain consistency and prevents syntax errors when editing markup.

### ES7+ React/Redux/React-Native snippets

<https://marketplace.visualstudio.com/items?itemName=dsznajder.es7-react-js-snippets>

Provides handy code snippets for React, Redux, and React Native. Speeds up development with short triggers for common patterns and hooks.

### ESLint

<https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint>

Integrates ESLint directly into VS Code. Highlights code issues and helps you follow consistent code quality and style rules.

### Oxc

<https://marketplace.visualstudio.com/items?itemName=oxc.oxc-vscode>

A fast and efficient JavaScript/TypeScript linter and compiler. Provides real-time feedback on code quality and performance.

## 😊 Nice to have

### Duplicate Action

<https://marketplace.visualstudio.com/items?itemName=mrmlnc.vscode-duplicate>

Quickly duplicate files or folders in your workspace. Useful for copying components or templates without leaving the editor.

### EditorConfig

<https://marketplace.visualstudio.com/items?itemName=EditorConfig.EditorConfig>

Maintains consistent coding styles across different editors and teams. Reads settings from a `.editorconfig` file in your project.

### Error Lens

<https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens>

Shows inline errors and warnings directly in your code. Makes debugging faster by avoiding the need to check the Problems panel.

### Multiple cursor case preserve

<https://marketplace.visualstudio.com/items?itemName=Cardinal90.multi-cursor-case-preserve>

Preserves letter case when editing multiple selections. Ideal for refactoring variable names without losing capitalization.

### Prettier - Code formatter

<https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode>

Automatically formats your code to follow a consistent style. Works with JavaScript, TypeScript, HTML, CSS, and more.

### Pretty TypeScript Errors

<https://marketplace.visualstudio.com/items?itemName=yoavbls.pretty-ts-errors>

Improves the readability of TypeScript error messages. Makes complex compiler errors easier to understand.

### Twoslash Query Comments

<https://marketplace.visualstudio.com/items?itemName=Orta.vscode-twoslash-queries>

Allows you to run TypeScript queries directly in comments using the `// ^?` syntax. Great for learning and debugging TypeScript types.
